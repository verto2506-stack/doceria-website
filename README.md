# 🍰 Doceria Social - Site de Doceria

Site responsivo e moderno de uma doceria fictícia, inspirado no design do Cake Social, totalmente em português brasileiro.

## 📋 Características

- ✨ Design elegante e responsivo
- 🎨 Paleta de cores moderna (rosa pastel e tons terrosos)
- 📱 Totalmente responsivo (Mobile, Tablet, Desktop)
- 🛒 Carrinho de compras interativo
- 📧 Newsletter com validação
- ⚡ Animações suaves e agradáveis
- 🎯 Navegação intuitiva
- ♿ Design acessível

## 🏗️ Estrutura do Projeto

```
doceria-website/
├── index.html       # Arquivo principal HTML
├── style.css        # Estilos CSS
├── script.js        # Funcionalidades JavaScript
├── images/          # Pasta para imagens
└── README.md        # Este arquivo
```

## 🚀 Como Usar

1. Clone o repositório
2. Abra `index.html` em seu navegador
3. Customize as imagens na pasta `images/`
4. Atualize o conteúdo conforme necessário

## 📝 Personalização

### Adicionar novos sabores:
1. Adicione uma nova imagem em `images/`
2. Copie o HTML do `.flavor-card`
3. Atualize o nome e imagem

### Mudar cores:
Edite as variáveis CSS em `style.css`:
```css
:root {
    --primary-color: #d4707f;
    --secondary-color: #2d4a4a;
    /* ... mais cores ... */
}
```

### Adicionar links reais:
Substituia os `href="#"` pelos links reais de:
- Produtos
- Redes sociais
- Páginas internas
